# Contributing

CT Bridge welcomes context cards, terminology decisions, synthetic evals, documentation, and code.

## Context contributions

Explain:

- The source expression and practical meaning.
- Audience, platform, region, and register.
- When the proposed translation works and when it fails.
- Whether the expression is current, dated, ironic, or community-specific.
- The provenance and license of any example.

Do not submit private drafts, paid-course materials, private chat logs, or large excerpts from copyrighted writing. Prefer original synthetic examples.

## Pull requests

- Keep one linguistic decision or tightly related group per PR.
- Add or update an eval when the change affects behavior.
- Separate observations from personal preference.
- Describe privacy impact when changing feedback or telemetry code.
- Never add network submission without an explicit consent flow and payload preview.
