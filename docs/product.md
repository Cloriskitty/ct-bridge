# Product Shape

CT Bridge is one product with two invisible routes.

## Decode

The user supplies an English crypto post, screenshot, thread, or article and asks what it means. CT Bridge returns the smallest useful Chinese context card: direct meaning, tone, necessary background, and uncertainty.

## Publish

The user supplies Chinese writing, or a Chinese source plus an English draft. CT Bridge infers the least invasive editing boundary and returns publication-ready text. Long documents default to a clean copy and a comments copy when document tools are available.

## Front-end principle

Users should not need to understand internal modes, terminology schemas, or telemetry. They install one skill, provide content, and ask naturally.

The product should feel trustworthy because it:

- preserves the author's intended claim;
- explains culture without pretending every interpretation is certain;
- uses slang only when it belongs;
- keeps private content local by default;
- discloses when work becomes adaptation rather than translation.

## Out of scope for the first release

- Price prediction or trade signals.
- Automatic trading.
- KOL scoring.
- Wallet analysis.
- Social publishing.
- Online storage of user drafts.
- Automatic imitation of named writers.
