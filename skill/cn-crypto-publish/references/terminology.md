# Public terminology starter

These are contextual options, not fixed replacements.

| Chinese concept | Common English options | Decision note |
| --- | --- | --- |
| 接盘 | become exit liquidity; be left holding the bag | `exit liquidity` is more CT-native; the latter emphasizes loss. |
| 踏空 | miss the move; be sidelined | Choose based on whether the emphasis is price action or positioning. |
| 套牢 | be underwater; be trapped in a position | `underwater` is concise when unrealized loss is central. |
| 抄底 | buy the dip; try to catch the bottom | The second preserves skepticism about timing. |
| 砸盘 | dump; sell into the market | `dump` can imply aggressive or coordinated selling. |
| 拉盘 | pump; push the price higher | Avoid `pump` if manipulation is not implied by the source. |
| 土狗 | microcap token; low-quality speculative token | Transliteration rarely carries the intended meaning. |
| 聪明钱 | smart money | Established term, but preserve skepticism if the source is ironic. |
| 牛回速归 | we are so back; the bull market is back | The first is meme-native and usually playful or ironic. |

Before choosing slang, check audience, platform, author register, and whether the phrase changes the factual claim.
