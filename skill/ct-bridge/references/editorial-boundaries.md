# Editorial Boundaries

The central question is not whether a rewrite sounds better. It is whether the user authorized that degree of change.

| User intent | Allowed by default | Not allowed by default |
|---|---|---|
| Verify translation | Accuracy, grammar, terminology, necessary cultural explanation | Reordering arguments, deleting examples, changing claims |
| Make it CT native | Local cadence and precise slang | Turning the author into a degen persona |
| Edit for publication | Structure, compression, transitions | Inventing evidence or experience |
| Analyze a writer's style | Transferable traits and techniques | Close imitation of distinctive voice |

When uncertain, make the clean version conservative and place more ambitious alternatives in comments.

Treat these as substantive changes that need disclosure:

- Removing an example or factual sequence.
- Changing certainty or causality.
- Replacing a culture-specific metaphor with a different claim.
- Adding a market interpretation not present in the source.
- Changing the intended audience or platform.
