# English crypto context starter

These entries are interpretation prompts, not fixed dictionary replacements.

| Phrase | Practical Chinese meaning | Context warning |
| --- | --- | --- |
| probably nothing | 常用于反讽，暗示事情可能很重要 | 也可能只是已经用滥的 meme，不能单独证明立场。 |
| cooked | 状态很差、可能没救了 | 可以形容人、仓位、代币、项目或论点。 |
| we are so back | “又行了”“牛回速归” | 经常夸张或反讽，并不等于严肃判断牛市开始。 |
| it's over | “结束了”“没戏了” | 常和 `we are so back` 组成情绪钟摆梗。 |
| few | “懂的人很少” | 可能表达自信、制造稀缺感，也可能是在模仿或讽刺。 |
| talking your book | 观点受到自身持仓影响 | 不自动代表观点虚假或作者故意骗人。 |
| round-trip a trade | 浮盈全部回吐，回到起点附近 | 可能指价格，也可能指交易者的 PnL。 |
| midcurve | 嘲讽过度分析却错过简单结论的人 | 是社交身份攻击，不是技术分类。 |
| touch grass | 离开网络、回到现实 | 带有不耐烦或嘲讽意味，并非 crypto 专属。 |
| cope | 用解释安慰自己或回避失败 | 语气可从朋友间玩笑到直接攻击。 |
| exit liquidity | 成为更早卖出者的接盘资金 | 强调利益关系，不只是“亏钱的人”。 |
| full port | 几乎把整个投资组合押在一个方向 | 强烈口语化，不必然表示字面上的 100%。 |

Always check the author, audience, platform, timestamp, and surrounding conversation before selecting a Chinese rendering.
